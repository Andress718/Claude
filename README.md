# Editor de Video (navegador)

Editor gráfico que corre 100 % en el navegador, sin instalar nada.

**Uso:** abre `editor/index.html` en Chrome/Edge (o sirve la carpeta: `python3 -m http.server -d editor`).

## Funciones
- Importar videos e imágenes (botón o arrastrar y soltar); formatos 16:9, 9:16, 1:1, 4:5.
- Línea de tiempo: dividir (S), recortar arrastrando bordes, reordenar, zoom, deshacer (Ctrl+Z).
- **Subtítulos**: texto, tiempos (arrastra/redimensiona en la línea de tiempo), tipografía (incluye subir tu fuente),
  tamaño, negrita/cursiva, colores de texto/contorno/fondo, sombra, posición (arrastra sobre la vista previa),
  estilos rápidos, importar/exportar `.srt`.
- **Animaciones de texto**: fade, pop, deslizar, máquina de escribir, rebote, zoom, karaoke.
- **Transiciones** entre clips: fundido, a negro, deslizar, cortinilla, círculo, zoom (con crossfade de audio).
- **Animación de clip** (zoom/paneo) y corrección de color (brillo, contraste, saturación, desenfoque).
- Exportar a MP4/WebM (grabación en tiempo real con audio; mantén la pestaña visible).
